# 가분수를 대분수로 바꾸기 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 13/4
- 2. 새 문제 설명하기: 2와 3/4
- 3. 오류 탐정: 몫 2와 남은 1의 역할을 바꾸어 자연수 부분과 분자에 놓았습니다. 7÷3=2…1에서 몫 2와 나머지 1을 바꾸어 1과 2/3으로 적었습니다. / 7조각에서 만들 수 있는 전체 2묶음보다 한 묶음을 더 세었습니다. 7÷3=2…1의 몫 2에 1을 더해 3과 1/3으로 나타냈습니다.
- 4. 나가기 표
  1. 13/4
  2. 2와 3/4
  3. 분모만큼 묶인 수는 자연수, 남은 수는 분자가 된다.

## 슬라이드 확인 정답

- 출처 문항 g3s2-frac-11: 2와 1/3
- 출처 문항 g3s2-frac-12: 13/4
- 따라 풀기: 13/4
- 새 문제: 2와 3/4
- 오류 one-and-two-thirds: 몫 2와 남은 1의 역할을 바꾸어 자연수 부분과 분자에 놓았습니다. (7÷3=2…1에서 몫 2와 나머지 1을 바꾸어 1과 2/3으로 적었습니다.)
- 오류 three-and-one-third: 7조각에서 만들 수 있는 전체 2묶음보다 한 묶음을 더 세었습니다. (7÷3=2…1의 몫 2에 1을 더해 3과 1/3으로 나타냈습니다.)
- 오류 seven-fourths: 자연수 3에 분모 4를 곱하지 않고 3과 4를 바로 더했습니다. (3×4+1=13 대신 3+4=7로 계산해 7/4로 적었습니다.)
- 오류 three-fourths-convert: 자연수 3묶음이 각각 4조각이라는 점을 버리고 3을 그대로 분자로 썼습니다. (3×4+1을 하지 않고 자연수 3만 분자에 놓아 3/4로 적었습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 분모만큼 묶인 수는 자연수, 남은 수는 분자가 된다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
