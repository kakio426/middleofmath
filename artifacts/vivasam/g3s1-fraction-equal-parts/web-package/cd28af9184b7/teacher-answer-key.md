# 분수의 첫 조건, 똑같이 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 똑같은 크기 6조각으로 다시 나눠요
- 2. 새 문제 설명하기: 1/5
- 3. 오류 탐정: 나 그림의 네 조각 수만 보고 서로 다른 너비를 확인하지 않았습니다. 네 조각 조건만 적용해 너비가 1, 2, 1, 2인 나 그림을 1/4로 판단했습니다. / 다 그림의 조각 크기는 같지만 분모 4가 나타내는 조각 수를 3으로 바꾸었습니다. 전체가 같은 너비 3조각인 다 그림을 골라 1/3 구조를 1/4로 판단했습니다.
- 4. 나가기 표
  1. 똑같은 크기 6조각으로 다시 나눠요
  2. 1/5
  3. 분수로 나타내려면 전체를 똑같은 크기로 나누어야 한다.

## 슬라이드 확인 정답

- 출처 문항 g3s1-frac-01: 가 그림
- 출처 문항 g3s1-frac-02: 똑같은 크기 6조각으로 다시 나눠요
- 따라 풀기: 똑같은 크기 6조각으로 다시 나눠요
- 새 문제: 1/5
- 오류 four-unequal: 나 그림의 네 조각 수만 보고 서로 다른 너비를 확인하지 않았습니다. (네 조각 조건만 적용해 너비가 1, 2, 1, 2인 나 그림을 1/4로 판단했습니다.)
- 오류 three-equal: 다 그림의 조각 크기는 같지만 분모 4가 나타내는 조각 수를 3으로 바꾸었습니다. (전체가 같은 너비 3조각인 다 그림을 골라 1/3 구조를 1/4로 판단했습니다.)
- 오류 six-unequal: 민지의 종이띠가 여섯 조각이라는 수만 보고 서로 다른 너비를 그대로 허용했습니다. (여섯 조각 조건만 적용해 너비가 1, 1, 2, 1, 1, 1인 상태도 1/6이라고 판단했습니다.)
- 오류 five-equal: 조각 크기를 같게 고치면서도 분모 6이 나타내는 조각 수를 5로 바꾸었습니다. (똑같은 크기 5조각으로 다시 나누면 1/5인데 이를 1/6의 고침으로 판단했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 분수로 나타내려면 전체를 똑같은 크기로 나누어야 한다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
