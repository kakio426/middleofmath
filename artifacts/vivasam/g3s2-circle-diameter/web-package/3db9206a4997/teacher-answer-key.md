# 반지름 두 개가 만드는 지름 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 12cm
- 2. 새 문제 설명하기: 14cm
- 3. 오류 탐정: 지름이 중심의 양쪽 반지름으로 이루어진다는 점을 반영하지 않았습니다. 지름을 반지름과 같은 4cm라고 판단했습니다. / 반지름을 두 번 더하는 대신 같은 수끼리 곱해 지름을 구했습니다. 4+4=8 대신 4×4=16cm로 계산했습니다.
- 4. 나가기 표
  1. 12cm
  2. 14cm
  3. 지름은 중심을 지나며 반지름의 2배이다.

## 슬라이드 확인 정답

- 출처 문항 g3s2-circle-02: 8cm
- 출처 문항 g3s2-circle-04: 12cm
- 따라 풀기: 12cm
- 새 문제: 14cm
- 오류 4cm: 지름이 중심의 양쪽 반지름으로 이루어진다는 점을 반영하지 않았습니다. (지름을 반지름과 같은 4cm라고 판단했습니다.)
- 오류 16cm: 반지름을 두 번 더하는 대신 같은 수끼리 곱해 지름을 구했습니다. (4+4=8 대신 4×4=16cm로 계산했습니다.)
- 오류 6cm: 시계 중심에서 한쪽 가장자리까지의 거리만 지름으로 사용했습니다. (지름을 반지름 한 개 길이인 6cm라고 판단했습니다.)
- 오류 36cm: 중심 양쪽 6cm를 더하지 않고 반지름을 자기 자신과 곱했습니다. (6+6=12 대신 6×6=36cm로 계산했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 지름은 중심을 지나며 반지름의 2배이다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
