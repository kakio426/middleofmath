# 같은 묶음은 곱셈으로 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 30장
- 2. 새 문제 설명하기: 4×5=20개
- 3. 오류 탐정: 한 묶음의 수와 묶음 수를 곱하지 않고 한 번씩 더했습니다. 3×4 대신 3+4=7로 계산했습니다. / 네 묶음 안의 연필을 세지 않고 묶음 수만 전체라고 보았습니다. 4봉지의 묶음 수 4를 연필 전체 수로 사용했습니다.
- 4. 나가기 표
  1. 30장
  2. 4×5=20개
  3. 한 묶음의 수 × 묶음 수 = 전체 수

## 슬라이드 확인 정답

- 출처 문항 g3s1-mul-01: 3×4=12
- 출처 문항 g3s1-mul-02: 30장
- 따라 풀기: 30장
- 새 문제: 4×5=20개
- 오류 3plus4: 한 묶음의 수와 묶음 수를 곱하지 않고 한 번씩 더했습니다. (3×4 대신 3+4=7로 계산했습니다.)
- 오류 4-only: 네 묶음 안의 연필을 세지 않고 묶음 수만 전체라고 보았습니다. (4봉지의 묶음 수 4를 연필 전체 수로 사용했습니다.)
- 오류 11: 다섯 장이 여섯 번 반복되는 관계를 두 수의 합으로 바꾸었습니다. (5×6 대신 5+6=11로 계산했습니다.)
- 오류 6-only: 각 줄의 다섯 장을 반영하지 않고 줄 수만 전체라고 보았습니다. (6줄의 묶음 수 6을 붙임 딱지 전체 수로 사용했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 한 묶음의 수 × 묶음 수 = 전체 수 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
