# 그림 하나에 숨은 수 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 첫째 줄 8개, 둘째 줄 4개, 차이 4개.
- 2. 새 문제 설명하기: 두 공원 50그루, A가 B보다 10그루 더 많다.
- 3. 오류 탐정: 생각 A는 범례 적용을, 생각 B는 두 행 모두 선택·계산하는 단계를 놓쳤다.
- 4. 나가기 표
  1. 6명
  2. 별 5개
  3. 범례.

## 슬라이드 확인 정답

- 슬라이드 2: 생각 B. 별 4개×5권=20권.
- 슬라이드 5: 5, 10, 15, 20; 4×5=20권.
- 슬라이드 6: 첫째 줄 8개, 둘째 줄 4개, 차이 4개.
- 슬라이드 7: 두 공원 50그루, A가 B보다 10그루 더 많다.
- 슬라이드 8: 아래 칸 별 5개, 위 칸보다 2개 더.
- 슬라이드 9: 생각 A는 범례 적용을, 생각 B는 두 행 모두 선택·계산하는 단계를 놓쳤다.
- 슬라이드 10: 6명, 별 5개, 범례.

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 그림 수를 세고 범례의 값을 적용해 실제 수량으로 바꾼 뒤 두 행의 수량 차이를 설명한다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
