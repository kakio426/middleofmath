# 그림 하나에 숨은 수 — 슬라이드별 수업 설계 의도

- 교과목: 수학
- 대상: 초등 3학년 2학기
- 단원: 6. 그림그래프
- 수업 시간: 40분
- 핵심 관찰 행동: 그림 수를 세고 범례의 값을 적용해 실제 수량으로 바꾼 뒤 두 행의 수량 차이를 설명한다.
- 개인정보 원칙: 실제 학생 이름·얼굴·학급·댓글을 넣지 않고, 모든 학생 반응은 '생각 A/B' 같은 합성 예시로 표시한다.
