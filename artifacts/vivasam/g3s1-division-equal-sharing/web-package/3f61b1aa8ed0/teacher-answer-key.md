# 18개를 똑같이 나누면 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 4자루
- 2. 새 문제 설명하기: 18÷6=3개
- 3. 오류 탐정: 세 명이라는 나누는 수를 한 사람이 받는 수로 그대로 사용했습니다. 12÷3의 몫 대신 나누는 수 3을 답으로 놓았습니다. / 세 사람에게 반복해 나누지 않고 전체에서 사람 수를 한 번 뺐습니다. 12÷3 대신 12-3=9로 계산했습니다.
- 4. 나가기 표
  1. 4자루
  2. 18÷6=3개
  3. 전체 ÷ 묶음 수 = 한 묶음의 수

## 슬라이드 확인 정답

- 출처 문항 g3s1-div-01: 4개
- 출처 문항 g3s1-div-02: 4자루
- 따라 풀기: 4자루
- 새 문제: 18÷6=3개
- 오류 3: 세 명이라는 나누는 수를 한 사람이 받는 수로 그대로 사용했습니다. (12÷3의 몫 대신 나누는 수 3을 답으로 놓았습니다.)
- 오류 9: 세 사람에게 반복해 나누지 않고 전체에서 사람 수를 한 번 뺐습니다. (12÷3 대신 12-3=9로 계산했습니다.)
- 오류 5: 5×□=20에서 이미 보이는 상자 수 5를 빈칸의 수로 다시 사용했습니다. (5×□=20에서 찾아야 할 다른 요인 4 대신 알려진 요인 5를 빈칸에 놓았습니다.)
- 오류 15: 곱해서 20이 되는 수를 찾지 않고 전체에서 상자 수를 한 번 뺐습니다. (5×□=20의 빈칸 대신 20-5=15로 계산했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 전체 ÷ 묶음 수 = 한 묶음의 수 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
