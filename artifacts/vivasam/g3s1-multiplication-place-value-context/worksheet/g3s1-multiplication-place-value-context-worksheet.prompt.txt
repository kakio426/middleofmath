# 1. Scene:
초등학교 3학년 학생이 인쇄해서 연필로 직접 푸는 세로형 수학 활동지 한 장. 흰 종이 바탕에 보라색과 연보라색을 중심으로 사용하고, 노란색은 작은 강조에만 쓴다. 페이지 네 가장자리에는 약 6%의 안전 여백을 둔다. 좌상단에는 독립된 작은 로고 구역을 두고 둥근 보라색 구름 안에 흰 소문자 영문 로고를 넣는다. 우상단에는 이름 쓰는 칸을 둔다. 제목은 로고보다 충분히 아래에서 시작하는 별도 제목 구역에 크게 놓고, 로고와 제목 사이에 넉넉한 흰 여백을 둔다.

본문에는 같은 너비의 큰 문제 카드 세 개를 위에서 아래로 쌓는다. 카드 사이는 넓게 띄우고, 각 카드 안에서 문제 문장, 그림 자료, 선택지, 계산 칸이 서로 분명히 구분된다. 초등 3학년이 멀리서도 읽을 수 있는 큰 글자와 넉넉한 답쓰기 공간을 사용한다.

첫 번째 카드는 공책 상자 그림을 정확히 두 개만 가로로 배치한다. 두 상자는 같은 크기이며 각 상자 앞면에 42권이라고 또렷하게 적는다. 그림 아래에는 서로 떨어진 큰 선택 상자 세 개를 같은 크기로 배치하고 각 선택 상자 왼쪽에 빈 선택 원을 둔다. 선택지 아래에는 곱셈식을 쓰는 긴 빈칸을 둔다.

두 번째 카드는 공이 든 상자 그림을 정확히 세 개만 가로로 배치한다. 세 상자는 같은 크기이며 각 상자 앞면에 31개라고 또렷하게 적는다. 그림 아래에는 31을 30과 1로 나누어 계산하는 세 줄의 식을 놓고, 각 결과를 쓸 수 있는 긴 빈칸을 둔다.

세 번째 카드는 같은 23×3 문제에 대한 두 풀이를 좌우의 독립된 상자에 보여 준다. 첫 번째 풀이와 두 번째 풀이의 수학식은 줄마다 가지런히 정렬하고, 두 풀이 아래에는 알맞은 풀이에 표시할 빈 선택 원과 까닭을 한 문장으로 쓰는 넓은 줄을 둔다. 페이지 맨 아래에는 오늘의 핵심 관계를 한 줄로 크게 정리한다. 모든 카드와 글, 그림은 페이지 경계와 카드 경계 안쪽에 충분한 여백을 갖는다.
