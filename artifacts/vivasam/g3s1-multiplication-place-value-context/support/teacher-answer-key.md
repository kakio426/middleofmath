# 상자 수를 자릿값으로 곱하기 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 20×3=60 → 3×3=9 → 60+9=69
- 2. 새 문제 설명하기: 90+3=93개
- 3. 오류 탐정: 23의 20을 2로 줄여 십의 자리 값을 빠뜨린 식을 골랐습니다. 20×3=60을 2×3=6으로 줄여서 십의 자리 값을 빠뜨렸습니다. / 23이 세 번 반복되는 관계를 한 번 더하는 식으로 바꾸었습니다. 23×3을 나누어 곱하지 않고 23+3=26으로 나타냈습니다.
- 4. 나가기 표
  1. 20×3=60 → 3×3=9 → 60+9=69
  2. 90+3=93개
  3. 십의 자리 값과 일의 자리 값을 각각 곱한 뒤 두 부분곱을 더한다.
