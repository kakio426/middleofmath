# 그림그래프의 실제 차이 구하기 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 3명
- 2. 새 문제 설명하기: (5-2)×4=12명
- 3. 오류 탐정: 사과와 배의 그림 한 개 차이를 실제 과일 수로 바꾸지 않았습니다. 그림 차 (3-2)×2=2 대신 그림 차 3-2=1개만 답했습니다. / 그림 한 개 차이에 범례 2를 한 번 더 적용해 실제 차를 두 배로 만들었습니다. (3-2)×2=2에 다시 ×2를 하여 4개로 계산했습니다.
- 4. 나가기 표
  1. 3명
  2. (5-2)×4=12명
  3. 그림 수의 차이에 범례 값을 적용해야 실제 수량 차이가 된다.

## 슬라이드 확인 정답

- 출처 문항 g3s2-graph-02: 2개
- 출처 문항 g3s2-graph-04: 3명
- 따라 풀기: 3명
- 새 문제: (5-2)×4=12명
- 오류 1: 사과와 배의 그림 한 개 차이를 실제 과일 수로 바꾸지 않았습니다. (그림 차 (3-2)×2=2 대신 그림 차 3-2=1개만 답했습니다.)
- 오류 4: 그림 한 개 차이에 범례 2를 한 번 더 적용해 실제 차를 두 배로 만들었습니다. ((3-2)×2=2에 다시 ×2를 하여 4개로 계산했습니다.)
- 오류 1-student: 축구 그림 5개와 야구·농구 그림 4개의 차이만 세고 한 그림이 3명이라는 범례를 적용하지 않았습니다. (그림 차 (5-(3+1))×3=3 대신 그림 차 5-(3+1)=1명만 답했습니다.)
- 오류 9-students: 그림 한 개 차이에 범례 3을 적용해 3명을 구한 뒤 범례를 한 번 더 곱했습니다. ((5-(3+1))×3=3에 다시 ×3을 하여 9명으로 계산했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 그림 수의 차이에 범례 값을 적용해야 실제 수량 차이가 된다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
