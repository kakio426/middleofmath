# 분모가 같은 분수 비교하기 — 교사용 정답·관찰 포인트

- 2. 새 문제 설명하기: 7/8
- 3. 오류 탐정: 같은 크기 조각에서 더 적게 고른 2/5를 더 큰 분수로 선택했습니다. 분모 5가 같을 때 2<4인데도 2/5>4/5로 판단했습니다. / 분모가 같다는 사실만 보고 서로 다른 분자 2와 4를 비교하지 않았습니다. 분모 5=5만 확인해 2/5=4/5로 판단했습니다.
- 4. 나가기 표

## 슬라이드 확인 정답

- 출처 문항 g3s2-frac-02: 4/5
- 출처 문항 g3s2-frac-04: 6/7
- 따라 풀기: 6/7
- 새 문제: 7/8
- 오류 two-fifths: 같은 크기 조각에서 더 적게 고른 2/5를 더 큰 분수로 선택했습니다. (분모 5가 같을 때 2<4인데도 2/5>4/5로 판단했습니다.)
- 오류 same: 분모가 같다는 사실만 보고 서로 다른 분자 2와 4를 비교하지 않았습니다. (분모 5=5만 확인해 2/5=4/5로 판단했습니다.)
- 오류 three-sevenths: 같은 병과 같은 7등분에서 3조각 든 쪽을 더 많은 양으로 보았습니다. (분모 7이 같고 3<6인데 3/7>6/7로 판단했습니다.)
- 오류 same-seven: 두 분수의 분모 7이 같다는 이유로 주스 양도 같다고 보았습니다. (7=7만 비교하고 분자 3과 6을 무시해 3/7=6/7로 판단했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 분모가 같으면 분자가 큰 분수가 더 크다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
