# 전체와 부분을 분수로 읽기 — 교사용 정답·관찰 포인트

## 통합 활동지 정답

- 1. 따라 풀기: 3/8
- 2. 새 문제 설명하기: 3/7
- 3. 오류 탐정: 전체 5와 색칠한 2를 분수의 위아래에 반대로 놓았습니다. 색칠한 수/전체 수인 2/5를 전체 수/색칠한 수인 5/2로 뒤집었습니다. / 분모에 전체 5가 아니라 색칠하지 않은 세 조각을 놓았습니다. 전체 5조각 중 2조각을 색칠해 남은 5-2=3을 분모로 사용했습니다.
- 4. 나가기 표
  1. 3/8
  2. 3/7
  3. 전체 조각 수는 분모, 고른 조각 수는 분자에 쓴다.

## 슬라이드 확인 정답

- 출처 문항 g3s1-frac-03: 2/5
- 출처 문항 g3s1-frac-04: 3/8
- 따라 풀기: 3/8
- 새 문제: 3/7
- 오류 5of2: 전체 5와 색칠한 2를 분수의 위아래에 반대로 놓았습니다. (색칠한 수/전체 수인 2/5를 전체 수/색칠한 수인 5/2로 뒤집었습니다.)
- 오류 2of3: 분모에 전체 5가 아니라 색칠하지 않은 세 조각을 놓았습니다. (전체 5조각 중 2조각을 색칠해 남은 5-2=3을 분모로 사용했습니다.)
- 오류 8of3: 전체 피자 8조각과 먹은 3조각을 분수의 위아래에 반대로 놓았습니다. (먹은 수/전체 수인 3/8을 전체 수/먹은 수인 8/3으로 뒤집었습니다.)
- 오류 3of5: 분모에 전체 8이 아니라 먹지 않고 남은 다섯 조각을 놓았습니다. (전체 8조각 중 3조각을 먹어 남은 8-3=5를 분모로 사용했습니다.)

## 관찰 포인트

- 답이 맞는지만 보지 않고, 학생이 전체 조각 수는 분모, 고른 조각 수는 분자에 쓴다. 관계를 실제로 사용했는지 확인합니다.
- 계산, 단위, 설명 가운데 어느 지점에서 처음 달라졌는지 표시합니다.
- 같은 오류가 직접 문항과 새 문제에서 반복될 때만 다음 차시의 소집단 또는 개별 확인 근거로 사용합니다.
