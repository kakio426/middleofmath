## 최종 릴리스 게이트

- 콘텐츠 정적 감사, 교육과정 교차표·상위 학년 런타임 재현, 전체 타입 검사를 통과했다.
- 전체 단위·레거시 검사 595개, DB·pgTAP 486개, 브라우저 여정 35개를 모두 통과했다.
- 학생·교사·스튜디오 빌드와 런타임 번들 누출 검사, staging·production smoke 계약을 통과했다.
- 실제로는 한 줄인 대분수를 줄바꿈으로 오판하던 E2E 검사를 단일 박스·가로 넘침·`nowrap` 계약으로 교정했다.

## 공통 분수 표기 전수 점검

- 3~6학년 활성 세트의 분수 포함 판단 87개를 3개 화면에서 각각 순회해 총 261개 실제 학생 흐름을 통과했다.
- 문항·맥락·선택지의 슬래시 원문은 화면에서 분자·가로선·분모가 쌓인 교과서형 분수로 바꾸고, 스크린리더에는 `분모분의 분자` 순서로 읽힌다.
- 자연수·연산자·라디오 표시와 분수의 수직 중심 오차는 2px 이하로 제한하며, 대분수는 자연수와 분수를 한 묶음으로 유지한다.
- 390×844 전체 순회와 768×1024·1280×720 대표 화면에서 수직 중심과 가로 넘침을 확인했다.
- 공용 정적 감사가 음수 방향의 분수 기준선 회귀를 차단한다.
- 정답과 값이 같던 오답 4개를 서로 다른 유리수의 오개념 선택지로 교체했고, 6-2 과일 가격 문항의 곱셈·역순 오답을 실제 산출값에 다시 연결했다.
- 분수 단원의 정답·오답이 같은 값이면 실패하는 독립 산술 오라클과, 수직 중심 비교 대상을 찾지 못해도 실패하는 E2E 가드를 추가했다.

## 운영 규칙

- 문항 수를 늘리는 대신 같은 원인의 결함군을 한 번에 하나씩 닫는다.
- 각 학기는 콘텐츠·오답 근거·학생 시각자료·반응형 화면을 확인한다.
- 변경 범위의 집중 게이트와 실제 학생 화면을 확인한 뒤 같은 Codex 검증 에이전트의 승인을 받는다.
- 전체 단위·DB·E2E 릴리스 게이트는 8개 학기 루프를 마친 뒤 한 번 실행한다.
