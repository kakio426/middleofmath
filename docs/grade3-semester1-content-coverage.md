# 3학년 1학기 선수 진단 콘텐츠 커버리지

상태: 자동 검증 통과·교사 내용 검수 대기
대상 세트: `grade3-semester1` `1.0.0`
용도: 3학년 2학기 결과를 해석할 때 먼저 확인할 수 있는 이전 학기 단계

## 범위와 한계

2022 개정 교육과정은 3~4학년군 성취기준을 제시한다. 따라서 이 세트의
`3학년 1학기` 배치는 Middle of Math의 편집 결정이며, 교육부 또는
`DECK6/korean-elementary-learning-map`이 학기를 직접 확정했다는 뜻이 아니다.
외부 학습맵은 개별 학생 진단을 지원하지 않으므로 성취기준·주제·선수 후보를
대조하는 sidecar로만 사용한다.

이번 U8은 다음 네 단원만 다룬다.

| 단원 | 성취기준 앵커 | 단계 | 판단 | 관찰 초점 |
|---|---|---:|---:|---|
| 곱셈 | `[4수01-04]` | 2 | 4 | 같은 묶음, 두 자리 수의 자릿값 |
| 나눗셈 | `[4수01-05]`, `[4수01-06]` | 2 | 4 | 등분, 곱셈과 나눗셈의 관계 |
| 분수 | `[4수01-09]` | 2 | 4 | 등분할, 부분과 전체 |
| 길이 | `[4수03-16]` | 2 | 4 | 단위 선택, 단위 변환 |

합계는 4개 단원, 8개 학습 단계, 16개 판단이다. 각 단계에 직접 확인과
숫자만 바꾼 복제가 아닌 적용·전이 판단을 하나씩 둔다. 오답 32개는
16개 오개념으로 구분하며, 각 오개념을 두 판단에서 반복 관찰한다.

`[4수01-04]`, `[4수01-05]`, `[4수01-06]`, `[4수01-09]`는 교육과정의
3~4학년군 성취기준이므로 DB에서 `shared_across_semesters=true`인 공통
앵커로 관리한다. `[4수03-16]`은 현재 3학년 1학기 편집 배치에만 연결한다.
발행 정합성 가드는 공통 앵커 또는 해당 학기 전용 앵커만 허용한다. 따라서
2학기 전용 `[4수03-17]`을 1학기 세트에 넣거나, 1학기 전용
`[4수03-16]`을 2학기 세트에 넣으면 DB 발행 단계에서 거부한다.

세트의 canonical checksum은
`36075f86f51e8b7c19f5df87b681a1b98fc9db84d2d0415d6fcd48d11aa1d56d`로
고정한다. 실행 시 새 값을 자동 대입하지 않으며 콘텐츠가 바뀌면 검토를
거쳐 checksum도 명시적으로 갱신한다.

## 직접 확인과 적용·전이의 구분

- 두 자리 수 곱셈의 직접 확인은 `23×3`을 `(20×3)+(3×3)`으로 나타내는
  자릿값 구조를 묻고, 적용 판단은 `42×2`의 전체 수를 구한다. 초3-2의
  부분곱 계산 문항을 그대로 복제하지 않는다.
- 나눗셈의 등분 직접 확인은 12개를 3명에게 나누고, 적용 판단은
  5행 4열 배열을 보며 `5×□=20`의 빈칸을 찾는다.
- 분수 등분할은 문장만으로 판단하지 않는다. 같은 너비와 다른 너비를
  실제 비율로 그린 종이띠를 비교하고, 잘못 나눈 6조각을 어떻게 고칠지
  묻는다.
- 길이 문항은 연필·문 대상 그림 또는 `1m → ?cm`, `2km → ?m` 단위
  관계 그림을 제공한다. 의미 있는 시각자료 없이 단위 이름만 묻지 않는다.

`partition-diagrams`와 `length-relation` 시각자료는 TypeScript 스키마,
학생 UI, 스튜디오 요약, DB 런타임 스키마가 같은 계약을 사용한다. DB는
색칠 위치가 조각 수 범위를 벗어난 그림을 거부한다.

## 3학년 2학기와의 참고 연결

별도 선수 단계 그래프에 6개 연결을 둔다.

- 곱셈 자릿값 → 나눗셈의 의미
- 길이 단위 변환 → 들이 측정
- 두 자리 수 곱셈 → 3학년 2학기 곱셈 시작 단계
- 곱셈과 나눗셈의 관계 → 나머지가 있는 나눗셈
- 부분과 전체의 분수 → 3학년 2학기 분수 시작 단계
- 길이 단위 선택 → 무게 측정

모든 연결은 `advisory: true`다. 교사용 근거 화면에서 “먼저 확인할 이전
학기 단계 (편집 참고)”로만 표시하며, 학생의 부족·숙달을 자동 확정하거나
학부모 공유본에 넣지 않는다. 그래프의 학기 역행, 순환, 자기 연결, 중복,
없는 단계, 근거 없는 외부 주제 쌍은 발행 게이트가 차단한다.
검수 설명과 외부 주제 ID가 포함된 전체 그래프는 편집 패키지에만 두고,
교사 런타임에는 단계 연결에 필요한 최소 필드만 별도 투영한다. 전체
그래프가 등록돼야 하는 세트에서 그래프가 누락되면 발행 게이트가
`SPG_GRAPH_MISSING` 오류로 차단한다.

## 의도적으로 미룬 범위

평면도형, 시간, 덧셈과 뺄셈, 소수 등은 이번 세트에 임의로 넣지 않는다.
공식 학기 배치와 관찰 행동을 다시 검수한 뒤 U8b에서 별도 버전으로
추가한다. 현재 `1.0.0`은 `review` 상태이며 교사 내용 검수 전에는
학생에게 배정하거나 발행하지 않는다.

## 자동 완료 조건

- 콘텐츠 스키마와 canonical checksum이 일치한다.
- 5개 앵커, 8개 단계, 16개 판단이 교차표·블루프린트와 일치한다.
- 직접·전이 근거와 오답 32개의 도출 과정이 모두 검증된다.
- 6개 학기 간 연결은 모두 자문용이고 그래프 digest가 일치한다.
- 편집용 오개념 원장이 학생·교사 런타임 번들에 포함되지 않는다.
- 진단 무결성 오류는 0개다. 외부 후보 자료와 편집 학기 배치를 알리는
  경고 4개는 의도적으로 유지한다.
- DB pgTAP 107개에는 공통 앵커의 1학기 허용, 학기 전용 앵커의 교차 사용
  거부, 새 분할·길이 시각자료의 허용과 잘못된 색칠 위치 거부가 포함된다.
