# 태블릿 25대 실교실 리허설

## 준비

- 실제 수업과 같은 교실·Wi-Fi·태블릿 25대를 사용한다.
- 교사 기기에서는 staging 교사 화면을, 태블릿에서는 staging 학생 화면을 연다.
- `1번`부터 `25번`까지 번호와 개인 코드가 적힌 카드를 뒤집어 배부한다. 카드에는 학생 이름을 적지 않는다.
- 3학년 2학기 발행본에서 단원 하나만 배정한다. 학기 전체 배정은 사용하지 않는다.
- 교사 1명은 화면을 운영하고, 가능하면 보조 관찰자 1명은 시간과 질문만 기록한다.

## 20분 리허설 순서

1. `0–3분`: 25대가 학생 URL을 열고 학급 코드·번호·개인 코드로 입장한다.
2. `3–5분`: 모든 기기에 같은 단원 카드와 같은 문항 수가 표시되는지 확인한다.
3. `5–15분`: 학생 역할로 단원 활동을 끝낸다. 일부 기기는 답 변경과 `잘 모르겠어요`를 사용한다.
4. `15–18분`: 교사 화면에서 완료·진행 중·시작 안 함 수와 학생 25명의 상태를 확인한다.
5. `18–20분`: 완료 학생의 분석지를 열고 배정한 단원만 분석됐는지 확인한다.

## 통과 조건

- 10분 안에 25대 중 21대 이상이 입장한다.
- 모든 태블릿에 배정한 단원만 표시되고 문항 수가 서로 같다.
- 완료한 모든 기기의 문항 수와 서버에 저장된 고유 문항 수가 같다.
- 다른 단원의 문항 이벤트는 서버가 거부한다.
- 완료 학생 전원의 분석지가 생성되고 배정한 단원명과 근거만 표시된다.
- 교사 화면의 완료 수와 실제 완료 기기 수가 같다.
- 학생 화면에 정답, 오개념 이름, 교사용 설명이 나타나지 않는다.

## 즉시 중단

- 시작 10분 안에 5대 이상 입장하지 못한다.
- 완료 기기 한 대라도 응답 기록이 빠진다.
- 같은 문장이나 화면을 3명 이상 이해하지 못한다.
- 정답이나 학생 진단 단서가 학생 화면에 보인다.
- 완료 학생 2명 이상의 분석지가 생성되지 않는다.

중단 뒤에는 학생 답을 다시 입력해 맞추지 않는다. 사건기록 탭에 사실을 남기고 원인을 수정한 새 staging 배포에서 처음부터 다시 실행한다.
