# 3학년 2학기 파일럿 관찰 기록지

Google Sheet 하나에 아래 세 탭을 만든다. 학생 실명, 학교명, 학급명, 보호자 연락처는 입력하지 않는다. 학생은 서비스에 등록한 번호만 사용한다.

## 1. `학생비교` 탭

매주 분석지를 열기 전에 확인 학생 5명에게 예상되는 어려움을 먼저 적는다. 분석지를 본 뒤 같은 행의 나머지 칸을 채운다.

| 열 | 입력값 |
|---|---|
| 운영일 | `YYYY-MM-DD` |
| 주차 | `1`–`6` |
| 단원 | 곱셈, 나눗셈, 원, 분수, 들이와 무게, 그림그래프 |
| 학생 번호 | `1`–`25` |
| 사전 예상 | 한 문장 또는 `특이사항 없음` |
| 완료 여부 | 완료, 진행 중, 시작 안 함 |
| 걸린 시간(분) | 숫자 |
| 분석지에서 먼저 본 내용 | 한 문장 또는 `확정된 내용 없음` |
| 일치 정도 | 일치, 부분 일치, 불일치, 비교 불가 |
| 비교 이유 | 한 문장 |
| 추가 확인 필요 | 예, 아니요 |

확인 학생은 `1주 1–5번`, `2주 6–10번`, `3주 11–15번`, `4주 16–20번`, `5주 21–25번`으로 돌린다. 6주는 `1·6·11·16·21번`을 다시 확인해 분석의 반복성을 본다.

## 2. `주간결정` 탭

단원당 한 행만 기록한다.

| 열 | 입력값 |
|---|---|
| 운영일·주차·단원 | 학생비교 탭과 같은 값 |
| 참여 학생 수 | 숫자 |
| 완료 학생 수 | 숫자 |
| 완료율 | `완료 학생 수 / 참여 학생 수` |
| 평균 시간(분) | 완료 학생 기준 평균 |
| 분석지가 만든 다음 행동 | 전체 수업에서 다시 설명, 소집단 확인 활동, 학생 한 명에게 추가 질문, 별도 조치 없음 |
| 선택 이유 | 한 문장 |
| 다음 주 효과 | 도움 됨, 판단 어려움, 도움 안 됨, 아직 실행 전 |
| 중단 기준 발생 | 없음 또는 중단 기준 이름 |
| 운영 메모 | 기술 문제와 학생 질문만 짧게 기록 |

## 3. `사건기록` 탭

오류나 같은 질문이 반복될 때 한 건씩 기록한다. 응답 내용이나 개인 코드는 적지 않는다.

| 열 | 입력값 |
|---|---|
| 발생 시각 | `YYYY-MM-DD HH:mm` |
| 단원 | 단원명 |
| 종류 | 로그인, 저장, 문구 이해, 화면 표시, 분석지, 정답 단서, 기타 |
| 영향 학생 수 | 숫자 |
| 관찰 내용 | 재현 가능한 사실만 기록 |
| 즉시 조치 | 수업 계속, 해당 학생 중단, 전체 중단 |
| 해결 상태 | 확인 중, 수정 완료, 다음 운영 전 재검증 |

## 파일럿 종료 계산

- 행동 생성 단원 수: `분석지가 만든 다음 행동`이 `별도 조치 없음`이 아닌 단원 수
- 전체 완료율: 6주 완료 학생 수 합계 ÷ 6주 참여 학생 수 합계
- 분석 일치율: `일치` 행 수 ÷ `비교 불가`를 제외한 학생비교 행 수
- 성공 후보: 행동 생성 4단원 이상, 완료율 80% 이상, 평균 20분 이하, 일치율 70% 이상, 데이터 손실·진행 불가 오류 0건

이 수치는 학생의 능력 점수가 아니라 제품의 교실 활용 가능성을 판단하기 위한 운영 지표다.
