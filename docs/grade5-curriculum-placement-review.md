# 5학년 교육과정 배치 검토 원장

상태: **5학년 1·2학기 12개 단원 배치 승인 및 진단 세트 구현 완료**

## 결론

5학년은 2026 경기도교육청 수업-평가 계획 예시자료의 수학
성취기준-단원 표를 학기·단원 배치 기준으로 사용한다. DECK6의 학습맵은
성취기준 코드, 5~6학년군, 영역, 세부 주제와 선수 후보를 대조하는 용도이며
단원명 또는 학기 배치의 결정 근거가 아니다.

이 구분이 필요한 대표 사례는 `[6수01-12]`이다. DECK6에서는
`분수와 소수의 관계` 모듈에 있지만, 공식 2026 표에서는 5학년 1학기
4단원 `약분과 통분`에 배치된다.

## 승인 상태와 차단 규칙

- 1·2학기 12개 단원이 공식 배치표와 사용자 연속 구현 승인에 따라
  모두 `approved`다.
- 전역 상태는 `approved`이며, 문항 발행 여부는 별도의 콘텐츠·DB 발행
  게이트가 판단한다.
- 미승인 단원, 다른 단원의 성취기준 혼입, 승인 코드 누락, 잘못된 학기
  또는 단원 순서는 발행 게이트에서 오류로 차단한다.
- 스냅숏 포함 여부와 선수 후보는 승인 근거가 아니며 학생 진단 결과로
  직접 사용하지 않는다.
- 단원 순서는 경기도교육청 수업-평가 계획 예시의 내부 정렬 계약이다.
  검정 교과서 모든 발행사의 보편적 단원 번호로 학생·학부모 화면에
  제시하지 않는다.
- 2022 개정 교육과정의 2026학년도 초5 적용 시점을 정한 교육부 총론
  부칙 원문은 아직 별도 고정하지 못했다. 현재는 2026-02-25 공식 예시자료와
  `[6수]` 코드 사용을 근거로 하고, 해당 1차 사료는 후속 근거 보강 항목이다.

## 현재 범위

`kr-learning-map.grade56.snapshot.json`에는 5~6학년군 전체 45개 코드,
135개 세부 주제, 33개 상류 선수 후보를 고정했다. snapshot digest는
`sha256:7ec5c6254d89f931c73d1638cefcaf92b8f0102e98ae55258b0d7b3fd6b664cb`다.
이는 교육과정 대조 범위이며 상류 선수 후보를 학생 결손 판정으로 자동
승격하지 않는다.

5학년 1학기는 6단원·35단계·70문항, 2학기는 6단원·33단계·66문항이다.
두 학기 모두 각 단계에 direct·transfer 두 문항과 반복 관찰 가능한 두
오개념을 둔다. 교차표 digest는 1학기
`sha256:c4176ad2da5fd9a4ccd2705d9c1e448850394c731fe79207c2def68ce7af6352`,
2학기 `sha256:ea5116696bc1789ea844d73cd1b5a3ce8e785cd087cb2a653a6357fdd7811668`다.

약수와 배수의 범위는 자연수에서 `[6수01-04]`의 약수·공약수·최대공약수와
`[6수01-05]`의 배수·공배수·최소공배수를 목록으로 찾아 의미를 이해하는
데까지다. 최대공약수와 최소공배수는 두 수만 다루며 소인수의 곱,
소인수분해, 호제법, 세 수 문제, 분수의 약분·통분 적용은 넣지 않는다.
공식 지도 고려 사항의 ‘약수와 배수의 관계’는 별도 성취기준 단계로
승격하지 않고 상황 적용 문항의 보조 맥락으로만 사용한다.

대응 관계는 `[6수02-01]`의 완전한 대응표, 두 양의 규칙, □·△ 기호식,
한 연산 관계만 다룬다. 새 짝 찾기, 기호식, 두 양의 계산 방향, 기호식의
역방향 적용, 두 양의 변화량을 다섯 단계로 분리했다. 역방향·변화량
문항에는 관계식을 직접 제시해 관계 찾기와 적용을 한 문항에서 동시에
요구하지 않는다. 비율·백분율·함수·변수·정비례·그래프·좌표와 두 연산
관계는 제외한다.

A4-3 최종 독립 검증은 대응 관계 정답 10개와 오답 20개, 기호식·표·접근성,
4학년 규칙 단원과의 증분성, DB 비발행 경계를 다시 확인해
`VERDICT: APPROVE`, blocker·high·medium 0건,
`NEXT_UNIT_READINESS: READY`를 반환했다.

약분과 통분은 `[6수01-06]`, `[6수01-07]`, `[6수01-12]`를 크기가 같은
분수 만들기, 약분, 기약분수, 통분, 분모가 다른 분수 비교, 분수·소수
