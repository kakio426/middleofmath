# 보호자 안내문 초안

> 학교 관리자 확인 뒤 학교 양식과 표현에 맞게 수정해 사용합니다.

## 수학 생각 과정 확인 활동 안내

안녕하세요. 학생이 수학 문제를 어떤 기준으로 생각하는지 살펴보고 다음 수업을 준비하기 위해 3학년 2학기 수학 단원별 활동을 운영하려 합니다.

- 기간: 6주 동안 주 1회
- 시간: 단원당 약 15분
- 방법: 학교 태블릿으로 짧은 수학 문항에 응답
- 목적: 점수나 순위를 매기는 것이 아니라 다음 수업에서 다시 설명하거나 확인할 내용을 찾는 것

서비스에는 학생 실명과 학교 식별 정보를 입력하지 않습니다. 학생 번호와 선택한 별칭, 문항 선택, 답을 고치기까지 걸린 시간, `잘 모르겠어요` 사용 여부, 활동 완료 상태를 기록합니다. 결과는 담당 교사가 수업 계획을 세우는 데 사용하며 학생의 능력이나 학습 결손을 한 번의 활동으로 확정하지 않습니다.

파일럿 종료 뒤 운영에 필요한 기간 동안만 자료를 보관하고, 예정된 삭제일에 학생 응답과 분석 결과를 삭제합니다. 가정에 공유하는 결과표가 필요한 경우 담당 교사가 내용을 확인한 뒤 제공합니다.

활동이나 자료 처리에 관해 궁금한 점이 있으면 아래 담당자에게 문의해 주세요.

- 담당자: `[이름]`
- 문의 방법: `[학교가 승인한 연락 방법]`
- 운영 기간: `[시작일]`–`[종료일]`
- 삭제 예정일: `[종료일 + 90일]`
